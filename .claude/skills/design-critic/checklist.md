# Rakeen landing page — round-by-round history

Kept as evidence for `SKILL.md`'s critique checklist. Each round was technically well-executed and fully verified (typecheck/build/CSS-survival/overflow clean) and was still rejected — the failures were consistently aesthetic/emotional, not functional.

## Round 3 — "bolder full-bleed color blocks"
Alternating lime/graphite/ivory full-bleed sections, huge single-word chapter titles, tactile device shadows, cinematic minimal opening.
**Rejected**: "ولا واحد اعجبني... مو قاعد تعرف جوي" — didn't capture the intended feeling at all.

## Round — "concept exploration" (3-concept pitch)
Command Deck / Living Clock / The Receipt — three distinct narrative-device concepts presented for selection.
**Rejected** on the same grounds, without a preference among the three.

## Round 4 — "One Thread" (خط واحد)
An 8-section page with a persistent connecting thread line through three product "chains," converging into an animated dashboard waterfall. Included real hidden-detail additions (offline-mode toast, ZATCA QR badges, WhatsApp notification moment).
Built and deployed on "push it live" — but this masked that the underlying dissatisfaction had not actually been resolved yet.

## Round 5 — the first genuinely specific feedback
First first-person, concrete critique instead of a flat rejection:
- Still feels like "a beautiful software website," not "the system running my restaurant."
- Art direction feels generic/consumed, not distinctly Rakeen.
- **Dark sections make it too heavy** — explicit vision is bright, clean, light backgrounds, large white spaces.
- Visual chaos: presentation competes with the product instead of showcasing it.
- No distinct personality; could belong to any SaaS company.
- Proposed building 3–5 radically different creative directions with real moodboards before another full rebuild.

Response: built four **entirely light-toned** direction moodboards (المعرض/Gallery, الطاولة/Counter, الشاشة الواحدة/Single Screen, الشبكة الهادئة/Quiet Grid). Owner replied "All of them" — interpreted as "synthesize," built a combined page (whitespace bookends + sticky-frame content-swap + global restraint + one warm tactile receipt moment). Fully verified, deployed.

## Round 6 — the standard that stuck
**Rejected again**, then a fundamentally different instruction: "اسحب ع كل البرومات عندك" (forget all your prompts) — followed by the full real feature list pasted back verbatim, with:

> "لو قلت لك ابيك تعرض افضلهم صدق واللي يهم بطريقة جميلة هادية بسيطة بدون فلسفه كبيرة بدون غثى"
> (show only the features that genuinely matter most, presented beautifully, calmly, simply — no big conceptual philosophy, no bloat)

This explicitly rejected every prior narrative-device/concept-driven approach. The build that finally worked: five real features (الكاشير، المخزون والمشتريات، الأرباح، الضريبة، عملاؤك يرجعون), one repeated two-column template, zero color-block or dark sections, no unifying metaphor. Approved with a one-word "ارفعها" (upload it) after being shown a plain description of what changed.

## The pattern to internalize

Every rejected round passed all technical verification. The owner's rejections tracked exactly two things, in order of how load-bearing they turned out to be:
1. **Round 5's correction** (light/calm, real product as hero, no competing visual devices) — still fully in force.
2. **Round 6's correction** (no invented concept/philosophy at all, just the real most-important features, plainly, in one consistent template) — supersedes every earlier "invent a bold creative concept" instinct.

Apply both by default on this project going forward, not just when explicitly reminded.
